# Dunder Mifflin Paper Company — Warehouse Management System

A full-stack warehouse management system built for the Software Development Lab course, modeled around a paper distribution business workflow (order intake, manager approval, vendor procurement, and warehouse receiving/shipping).

> **Status:** In development. This README will be expanded with setup instructions, architecture overview, and screenshots as the project progresses.

## Tech Stack
- **Frontend:** React (Vite) + Tailwind CSS
- **Backend:** Node.js + Express
- **Database:** PostgreSQL

## Project Structure
\```
dunder-mifflin-wms/
├── docs/           # SRS, diagrams, API documentation
├── backend/        # Express API server
├── frontend/       # React client
└── database/       # SQL schema and seed data
\```

## Roles
- **Manager** (Michael Scott) — approves sales orders, manages employees
- **Warehouse Staff** (Daryl Philbin) — receives purchase orders, ships sales orders
- **Sales Representative** — manages assigned clients, creates sales orders
